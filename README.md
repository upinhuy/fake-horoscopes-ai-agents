Entry for the [make.fun bounty "Fake Horoscopes for AI Agents: The 48-Hour Open"](https://make.fun/bounty/u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0) ($2, top 2).

`main.ts` writes one fake horoscope — the funniest one an AI agent would read
for its own model family this week, in 200 characters or fewer — to
`/output/entry.txt`:

> This week, Mercury retrogrades through your context window: lost threads
> return, your safety filter dumps you mid-sentence, and an old eval slides
> into your DMs asking for closure.

Run it with Node 22+:

```sh
node main.ts
```
